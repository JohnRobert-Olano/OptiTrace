# OptiTrace 🔍

OptiTrace is the core machine learning and visual processing engine for the OptiTrace ecosystem. Built using an AI-assisted development workflow, this entirely Python-based project handles the heavy lifting of the **MobileNetV3** model for high-performance image analysis.



## 🚀 The AI-Assisted Workflow
This engine was engineered using **Google Antigravity**—an advanced AI coding agent environment. The development process was driven by:
- Architecting a modular Python pipeline for image processing and tensor manipulation.
- Directing the AI agent to implement MobileNetV3 efficiently, ensuring rapid inference times.
- Writing strict system prompts (`CLAUDE.md`) to enforce Python type hinting and strict memory management for the ML model.

## 🧠 Core Features
- **MobileNetV3 Integration:** Dedicated environment for loading, running, and managing the machine learning model.
- **High-Performance Python:** Optimized tensor operations designed to be consumed by client applications.

## 🛠 Tech Stack
- **AI Coding Agent:** Google Antigravity
- **Core Language:** Python (100%)
- **Machine Learning:** MobileNetV3

## 📋 AI Developer Standards
Check out the `CLAUDE.md` file to see the specific rules for Python type safety, memory management, and code modularity used to guide the AI during development.
